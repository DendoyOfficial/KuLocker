DESKRIPSI SINGKAT TENTANG "KULOCKER"
KULOCKER ADALAH SEBUAH PLATFORM WEBSITE JASA SEWA FASILITAS LOKER KAMPUS YANG DICIPTAKAN UNTUK MEMPERMUDAH MAHASISWA DALAM MENGAKSES LOCKER UNTUK MENYIMPAN BARANG.

ROLE
1. Mahasiswa (User): Pihak yang menyewa atau menggunakan loker. Fokus mereka adalah kemudahan akses dan keamanan barang.
2. Admin Kulocker(IT Support): Pihak yang mengelola sistem web, basis data mahasiswa, dan pemeliharaan server atau integrasi hardware.

FITUR UNGGULAN
1. Smart Accses dan booking
2. Security monitoring
3. Management System

TECHSTACK USING :
1. HTML
2. JAVASCRIPT
3. CSS
4. TAILWIND CSS
5. PHP
6. XAMPP/SQL

DBMS
- konfigurasi KuLocker berbasis client server sederhana dengan fokus pada akses digital, keamanan, dan manajemen data loker.
