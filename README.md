DESKRIPSI SINGKAT TENTANG "KULOCKER"
KULOCKER ADALAH SEBUAH APLIKASI YANG DICIPTAKAN UNTUK MEMPERMUDAH MAHASISWA DALAM MENGAKSES LOCKER UNTUK MENYIMPAN BARANG.

ROLE
1. Mahasiswa (User): Pihak yang menyewa atau menggunakan loker. Fokus mereka adalah kemudahan akses dan keamanan barang.
2. Petugas/Admin Kampus: Staf yang bertanggung jawab mengelola area loker, melakukan pengecekan fisik, dan menangani kendala teknis (misalnya loker macet).
3. Super Admin (IT Support): Pihak yang mengelola sistem web, basis data mahasiswa, dan pemeliharaan server atau integrasi hardware.

FITUR UNGGULAN
1. Smart Accses dan booking
2. Security monitoring
3. Management System

TECHSTACK USING :
1. HTML
2. JAVA
3. CSS
4. PHP
5. XAMPP/SQL

DBMS
